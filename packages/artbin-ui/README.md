# Artbin CLI UI

React components and tree helpers for the Artbin CLI scan interface. Public entry points are declared in `package.json`; implementation is in `src/`. This package is consumed by `apps/artbin-cli` and does not import an app.

From the Tea root, run `npm ci` and `npm run check --workspace @artbin/ui`. The web app's visual system remains in `apps/artbin/app/ui`.
