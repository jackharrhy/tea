# @tea/maps-compiler

This local Node service runs an installed ericw-tools `qbsp → vis → light` pipeline, or an explicitly configured q2tool pipeline, for the Maps editor. `src/routes.ts` and `src/app.ts` implement its Remix 3 HTTP routes; `src/server.ts` adapts them to Node. `src/compiler.ts` owns temporary files, process limits, and the native compile pipeline. `src/launch.ts` allows an optional, explicitly configured local game launch. The executable tools are external dependencies: this workspace does not vendor or distribute them. The [MIT license](LICENSE) accompanies the copied source.

From the repo root, run `npm ci`, build `@jackharrhy/tea-maps-renderer`, `@tea/maps-editor`, and `@tea/maps-protocol`, then run `npm run check --workspace @tea/maps-compiler`. The check typechecks, runs tests in `__tests__/`, and builds the Node entry point. Configure `ERICW_QBSP`, `ERICW_VIS`, and `ERICW_LIGHT` as absolute executable paths and run `npm run dev --workspace @tea/maps-compiler`. For Quake II, set `TEA_MAPS_GAME_PROFILE=quake2` and `TEA_MAPS_Q2TOOL` instead. A Quake II request can supply contained WAL, PNG, TGA, WAL metadata, and palette files; they are placed in a temporary game tree. When a request supplies assets and `TEA_MAPS_GAME_DIR` is unset, q2tool uses that temporary tree as its game directory. A request containing project assets is rejected when `TEA_MAPS_GAME_DIR` is set, since q2tool cannot safely layer those assets over an external directory. Requests without project assets continue to use the configured directory. The default listener is `127.0.0.1:8788`; `TEA_MAPS_COMPILER_HOST` and `TEA_MAPS_COMPILER_PORT` override it. `GET /health` reports whether the toolchain is configured; `GET /capabilities`, `POST /compile`, and `POST /launch` are the helper API.

Tea-specific environment names identify this helper after the Worldview cutover. Request, asset, concurrency, log, timeout, and artifact limits remain configurable through `TEA_MAPS_COMPILER_*`. Browser origins must be listed in `TEA_MAPS_COMPILER_ORIGINS`; the default allows Tea Maps at `http://localhost:8790` or `http://127.0.0.1:8790`. The original `WORLDVIEW_*` settings are ignored by this workspace. Launch is disabled unless its absolute executable and directory settings are supplied. See the [Worldview compiler guide](https://github.com/jackharrhy/worldview/blob/main/apps/compiler-service/README.md) for background on game profile and launch settings.

The Dockerfile packages the Node helper without native game tools. For a local container, set `ERICW_TOOLS_DIR` to an installed ericw-tools directory and run `docker compose --profile native-compiler up --build maps-compiler`. The compiler remains on the private Compose network; do not add a public route. A production host must also enforce resource limits and mount its trusted native tools read only. Host operations belong in the infrastructure repo. Newport now runs Tea's compiler service.
