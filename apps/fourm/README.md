# 4orm on Celld

Status: faithful-parity rework in progress. Earlier fixture preview and tests are
POC evidence, not migration acceptance. See `docs/parity.md`.

Development now lives at `apps/fourm` in the primary Harrhy checkout on
`work/fourm-parity`, derived from the native candidate rather than merged into
`main`. The former standalone candidate worktree is retired; this is still the
same Celld-native app, not a Python proxy or a production cutover.

An isolated native port of the Python community app. Remix owns HTTP routes and
server-rendered UI; SQLite Durable Objects own members, content, invitations and
sessions; the `MEDIA` R2 binding owns upload bytes. No request is forwarded to the
Python service.

The candidate keeps explicit issuer/subject links and original numeric ownership
IDs. Browser cookies are host-only and expire within one hour. Local disabled and
admin flags remain authoritative; API operations additionally require the exact
central permission scope and project role. Shared-runtime bindings do not grant
access to private pages, sessions or another app's database.

## Check

From the monorepo root:

```sh
npm ci
npm run check --workspace @harrhy/fourm
```

`__tests__/` contains model, API-format, rendering and actual browser checks.
Worker types are generated by `types:worker`. `wrangler deploy --dry-run` bundles
without publishing. Use the fork binary pinned by Ref's Dockerfile for Celld;
the older globally installed binary is not the tested runtime.

## Existing private review

The preserved prod-derived human-review cohort, corrected test authority, media,
keys and evidence live in ignored `.review/`. The current human-review state is
`.review/private-tailnet-cohort-20261113`; its private ingress assets/config live
in `.review/access-current`. These are not disposable bootstrap fixtures. Do not
reseed them or start a second writer. The existing review supervisor and private
access proxy own that instance; coordinate a stop/start before changing its
runtime configuration. Generated configs retained in `.review/retired-worktree`
are historical evidence, not launch inputs.

A preview hostname change must preserve its canonical fixture issuer unless an
explicit identity-link migration is reviewed: member links use exact issuer and
subject. A named ingress without trusted Tailnet identity must require the
separate review key, never fabricate an identity header or treat DNS as access
control.

Python production and its separate oracle interpreter/state remain independent
and untouched. A long-term shared Celld host is a direction, not a reason to
combine app stores or redesign authority during this consolidation.

## Disposable review

From this app directory, using the Celld 0.6.2 fork pinned by Ref:

```sh
CELLD_BIN=/absolute/path/to/celld node scripts/review.mjs
```

Open `http://127.0.0.1:18944`. The disposable issuer is on 18945; its upstream
provider is on 18946. “Continue as local user” signs in the fixture Jane. The
runner owns an isolated SQLite object authority, replica and fixture key under
ignored `.review/candidate`; it never contacts production Auth. Stop it with
SIGTERM and wait for child shutdown before moving state.

Set `FOURM_REVIEW_STATE`, `FOURM_REVIEW_PORT`, `FOURM_REVIEW_ISSUER_PORT`,
`FOURM_REVIEW_PROVIDER_PORT`, `FOURM_REVIEW_ORIGIN` and `FOURM_REVIEW_ISSUER`
for an independent instance or existing private HTTPS proxy. Each instance needs
unique ports and state. No route or domain is created by the runner.

The earlier `test:celld` suite covers the POC's authority/recovery mechanics,
but its browser selectors still target the superseded interface. It must be
updated to the source workflows before it can count as current acceptance.
Released CLI API smoke is separate from an interactive CLI sign-in test.

The same-content oracle comparison is `npm run test:parity`; it requires the
private prepared cohort and owned loopback listeners described in
[the parity work log](docs/parity.md). It does not fetch production data.
