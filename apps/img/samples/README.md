# Sample animations

`hummingbird.gif` is a three-second excerpt (seconds 1 through 4) of [Hummingbird.ogv](https://commons.wikimedia.org/wiki/File:Hummingbird.ogv) by Rishiraj Sahoo, used under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). This GIF adaptation uses the same license. The video was trimmed, resized to 480 × 270, reduced to 15 frames per second, and converted to a looping GIF without audio.

`blue-block.gif` is the small generated fixture used by the automated tests.
