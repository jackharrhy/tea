# Caption fonts

Inter, Anton, Bangers, and Bebas Neue ship inside the executable. Each retains its original SIL Open Font License. Inter’s license is in `LICENSE.txt`; other licenses are beside their font files. Impact is available through the system font catalog when installed; it is not redistributed.

New font files are unmodified from the Google Fonts repository, pinned to commit `86aced91de05cd4f96a06838124cca45be337b2b`.
