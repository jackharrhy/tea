# @tea/maps-service

This is Tea Maps' hosted-project service. It owns users, OAuth sessions, projects, maps, resources, build requests, collaboration tickets, and MCP endpoints. `src/server.ts` is the Node entry point; `src/database.ts` and `src/blob-store.ts` own local persistence. The service consumes Tea's renderer, editor, and protocol packages. It uses `data/maps` by default, port `8792`, and a separate collaboration ticket secret. The [MIT license](LICENSE) accompanies the copied source.

From the repo root, run `npm ci`, build `@jackharrhy/tea-maps-renderer`, `@tea/maps-editor`, and `@tea/maps-protocol`, then run `npm run check --workspace @tea/maps-service`. The check typechecks, runs the service tests in `__tests__/`, and builds the Node entry point. `npm run dev --workspace @tea/maps-service` starts the local service. `GET /health` reports its status. Set `TEA_MAPS_URL` (the public Maps UI origin, default `http://localhost:8790`), `TEA_MAPS_DATA_ROOT`, `TEA_MAPS_COLLABORATION_URL`, and `TEA_MAPS_REALTIME_TICKET_SECRET` as needed. OAuth requires a compatible Fourm service with a public `tea-maps` client (the `FOURM_CLIENT_ID` default) and a registered `${TEA_MAPS_URL}/auth/callback` redirect. Set `TEA_MAPS_QUAKE_COMPILER_URL`, `TEA_MAPS_GOLDSRC_COMPILER_URL`, or `TEA_MAPS_GOWER_COMPILER_URL` to enable hosted builds for those games. `TEA_MAPS_ADDITIONAL_PUBLIC_ORIGINS` accepts a comma-separated set of extra trusted UI origins. Optional MCP token introspection uses `TEA_MAPS_FOURM_INTROSPECTION_SECRET` and `TEA_MAPS_FOURM_INTROSPECTION_CLIENT_ID` (default `tea-maps-service`). `TEA_MAPS_MCP_SCOPE` changes the required and advertised OAuth scope; it defaults to `maps:admin`. Host and production operations belong in the infrastructure repo.

Artbin search and import are enabled only when `TEA_MAPS_ARTBIN_URL`, `AUTH_ARTBIN_CLIENT_ID`, and `AUTH_ARTBIN_CLIENT_SECRET` are all set. Set `AUTH_ISSUER` to the HTTPS central issuer and `AUTH_ARTBIN_PROJECT_ID` to the Artbin project. Register a central machine identity with only `assets-read` and `assets-content` roles for that project. The service uses those credentials only on the server and copies imported bytes into its own blob store.

Remix 3 selects all public HTTP routes through a persistent router in `src/service-routing.ts`. Controllers and HTTP helpers use Web Requests and Responses; `remix/node-fetch-server` bridges the Node listener. Large resource uploads and downloads remain streamed. The Tea Maps Worker passes `/api/*` and `/auth/*` to this service on the same browser origin. The optional static root is disabled by default because the Worker serves the UI.

For a local container run, use `docker compose up --build -d maps-service` from the Tea root. This starts the separate Maps collaboration Worker on `127.0.0.1:8787` and serves the service on `127.0.0.1:8792`, matching the Maps UI's local proxy defaults. The service keeps its database and blobs in the `maps-service-data` volume; collaboration has a different volume. Both use `MAPS_REALTIME_TICKET_SECRET` from Compose. `FOURM_URL` defaults to `http://host.docker.internal:8000` in this local setup and may be set to another reachable Fourm origin. The container runs as `node`, has a health check at `/health`, and does not contain game assets or a native compiler. The local compiler remains a separate trusted-machine helper.

Compose passes the optional Artbin endpoint and central machine settings from the local environment. When Artbin runs on the host, use `http://host.docker.internal:5175` for its URL rather than the browser's `localhost` address. Supply the central machine ID, secret and project ID described above. Token requests use the project audience and explicit asset-role scopes; credentials are never sent over HTTP or through redirects.

`GET /api/maps/:mapId/checkpoints` lists authoritative map-cell checkpoints for project members; editors can create one with `POST` on the same path. `GET /api/maps/:mapId/checkpoints/:checkpointId` reads its original source for members.

The MCP endpoint advertises `tea_maps_*` tools and returns Tea `/projects/:id` links from browser grants. The default Fourm token scope is `maps:admin`.

Tea issues `tea_maps_session`, `tea_maps_automation`, and `tea_maps_oauth` cookies.
