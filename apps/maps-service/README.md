# @tea/maps-service

This is Tea's bake copy of Worldview's hosted-project service. It owns users, OAuth sessions, projects, maps, resources, build requests, collaboration tickets, and MCP endpoints. `src/server.ts` is the Node entry point; `src/database.ts` and `src/blob-store.ts` own local persistence. The service consumes Tea's renderer, editor, and protocol packages. It has a separate default data directory (`data/maps` under this workspace), port (`8792`), public origin, and collaboration ticket secret. The original deployment and data remain separate.

From the repo root, run `npm ci`, build `@tea/maps-renderer`, `@tea/maps-editor`, and `@tea/maps-protocol`, then run `npm run check --workspace @tea/maps-service`. The check typechecks, runs the service tests in `__tests__/`, and builds the Node entry point. `npm run dev --workspace @tea/maps-service` starts the local service. `GET /health` reports its status. Set `TEA_MAPS_URL` (the public Maps UI origin, default `http://localhost:8790`), `TEA_MAPS_DATA_ROOT`, `TEA_MAPS_COLLABORATION_URL`, and `TEA_MAPS_REALTIME_TICKET_SECRET` as needed. OAuth requires a compatible Fourm service. Set `TEA_MAPS_QUAKE_COMPILER_URL`, `TEA_MAPS_GOLDSRC_COMPILER_URL`, or `TEA_MAPS_GOWER_COMPILER_URL` to enable hosted builds for those games. `TEA_MAPS_ADDITIONAL_PUBLIC_ORIGINS` accepts a comma-separated set of extra trusted UI origins. Optional MCP token introspection uses `TEA_MAPS_FOURM_INTROSPECTION_SECRET` and `TEA_MAPS_FOURM_INTROSPECTION_CLIENT_ID` (default `tea-maps-service`); the `worldview:admin` scope remains the copied Fourm contract during the bake period. The service ignores the corresponding `WORLDVIEW_*` settings, so an original deployment’s compiler and origin settings do not leak into Tea. Host and production operations belong in the infrastructure repo.

Remix 3 selects all public HTTP routes through a persistent router in `src/service-routing.ts`. Controllers and HTTP helpers use Web Requests and Responses; `remix/node-fetch-server` bridges the Node listener. Large resource uploads and downloads remain streamed. The Tea Maps Worker passes `/api/*` and `/auth/*` to this service on the same browser origin. The optional static root is disabled by default because the Worker serves the UI. Do not point the service at Worldview's data directory, public origin, or existing map cells.

`GET /api/maps/:mapId/checkpoints` lists authoritative map-cell checkpoints for project members; editors can create one with `POST` on the same path. `GET /api/maps/:mapId/checkpoints/:checkpointId` reads its original source for members.
