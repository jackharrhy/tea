  The broad lower receiving-floor contact reuses pocket.wav with a deeper pitch

  Rolling gain/rate follows actual speed and stage.
  Position uses 75% center / 25% HRTF with identical distance loss on both paths.

Reproduce the felt rolling loop with Python 3 and ffmpeg (in this directory):
  import subprocess, array, math, wave
  for src, out, start, end, overlap, cutoff in [
      ('cloth-roll.mp3', 'felt-roll.wav', .25, .62, .08, 1600),
  ]:
      data = array.array('f', subprocess.check_output([
          'ffmpeg', '-v', 'error', '-i', src, '-af',
          f'atrim=start={start}:end={end},asetpts=PTS-STARTPTS,highpass=f=60,lowpass=f={cutoff}',
          '-ac', '1', '-ar', '44100', '-f', 'f32le', '-']))
      n = round(overlap * 44100)
      result = list(data[n:-n])
      for i in range(n):
          w = (1 - math.cos(math.pi * i / (n - 1))) / 2
          angle = w * math.pi / 2
          result.append(data[-n+i] * math.cos(angle) + data[i] * math.sin(angle))
      pcm = array.array('h', (round(max(-1, min(1, x)) * 32767) for x in result))
      with wave.open(out, 'wb') as f:
          f.setnchannels(1)
          f.setsampwidth(2)
          f.setframerate(44100)
          f.writeframes(pcm.tobytes())
  The output is the source middle followed by blended tail/head, so its end
  joins the next middle naturally. The seam is never independently faded out.
