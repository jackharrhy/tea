# Maps workspace

Read this README and the Tea root guidance before editing. Keep app routes and UI in this workspace, and import the renderer and editor through their public package entry points. Use Remix 3 controllers and `css(...)` mixins for static UI. Do not add game assets to the repository. The local Celld Worker owns viewer and editor presentation; hosted storage and collaboration belong to separate workspaces. Set runtime backend origins with `CELLD_VAR_MAPS_SERVICE_ORIGIN` and `CELLD_VAR_MAPS_COLLABORATION_ORIGIN`. Run this app's `check` and the affected package checks after changing their interfaces.
